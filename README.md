# College Canteen Pre-Ordering System

A web-based application that allows college students to browse the canteen menu and pre-order food.

## Canteen Panel

This module is responsible for managing canteen operations.

### Technology Stack
- React.js
- Node.js
- Express.js
- MongoDB

### Features
- Dashboard and order overview
- Food item management
- Category management
- Food availability management
- Order management
- Order history
